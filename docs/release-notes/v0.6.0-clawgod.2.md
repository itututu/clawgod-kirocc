# ClaudeCode Kiro v0.6.0-clawgod.2

Windows 安装与 Kiro 凭据诊断修复版，中文说明优先。

## 主要更新

- Windows 安装器在构建前读取 `go.mod`，显示实际使用的 `go.exe` 路径和
  版本。Go 版本过低时直接给出 `winget`、`where.exe go` 和 PATH 排查步骤，
  不再只显示 `go.exe: unknown GOEXPERIMENT jsonv2`。
- macOS/Linux 和 Windows 安装器在构建前校验 Kiro API Key 或现有 Kiro CLI
  登录数据库，避免安装完成后首次请求必然返回 401。
- 启动器在拉起网关前再次校验凭据；复用已有网关时会验证当前本地代理
  Token，明确区分本地 `KIROCC_API_KEY` 冲突和上游 Kiro 登录失效。
- Doctor 以脱敏方式检查 `kiro-cli whoami`，不会把账户信息输出到日志。
- 文档明确流量边界：Kiro CLI 只负责创建和维护登录凭据，实际对话与
  WebSearch 请求由 kirocc 网关直接发往 Kiro。

## Windows 更新与安装

源码安装要求 Go 1.26.1+。已有克隆先更新：

```powershell
git pull origin main
winget upgrade --id GoLang.Go -e

# 打开新的 PowerShell 后确认当前版本和路径
where.exe go
go version

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
.\scripts\doctor.ps1
```

默认使用官方 Claude Code runtime，不安装 ClawGod。需要 Patch runtime 时才加
`-WithClawGod`。

## Release 制品边界

Release 压缩包只包含独立 `kirocc` 网关二进制和公开文档：Windows 使用 ZIP，
macOS/Linux 使用 tar.gz。完整 `claude-kiro` 必须克隆源码运行安装器；Release
不包含 Claude Code、ClawGod runtime、凭据、会话或用户配置。

## 验证

- Linux：安装文件校验、默认安装冒烟测试、lint、Go race 测试。
- Windows：PowerShell 5.1 语法和帮助入口、Go 测试、Windows 网关构建、默认
  安装与启动冒烟测试。
- GoReleaser：macOS、Linux、Windows 的 amd64/arm64 六个目标及统一
  `checksums.txt`。

## English summary

This prerelease adds an early Windows Go toolchain check with the exact active
`go.exe` path, Kiro credential preflight for both installers and launchers,
redacted `kiro-cli whoami` diagnostics, and clearer separation between Kiro CLI
login maintenance and gateway request traffic. Release archives contain only
the standalone gateway and public documentation; clone the repository for the
managed `claude-kiro` installation.
